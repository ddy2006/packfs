# 打包工具
## 打包输入
参数 : 
- `--entry` : 入口文件路径
- `--output` : 输出文件路径
- `--filelist` : 文件列表路径, 包含需要打包的文件路径, 每行一个文件路径,列表文件名即为打包文件最终的文件名
- `--compress-algorithm` : 是否进行压缩, 可选值为 `none','zstd','xz'`, 默认为 `none`
- `--output-format` : 输出格式, 可选值为 `bin','tar','iso'`, 默认为 `bin`

## 打包输出
- 打包文件 : 输出路径下的打包文件, 文件名为列表文件名,后缀为输出格式对应的后缀

## 打包流程
1. 读取文件列表, 获取需要打包的文件路径
2. 根据输出格式, 创建对应的打包文件
3. 将每个文件的内容写入打包文件中, 并记录每个文件在打包文件中的位置和大小至数据库中
4. 计算校验和，并将校验和记录到数据库中
5. 关闭打包文件, 完成打包操作
